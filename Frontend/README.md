# HiumanLab Frontend

## Structure

- `src/app` — application shell and view composition.
- `src/components` — reusable user-interface components.
- `src/i18n` — translations and language helpers.
- `src/styles/base` — global design foundations and shared layouts.
- `src/styles/components` — component-specific styles.
- `src/legacy` — retained files from the earlier vanilla-JavaScript prototype; not used by the Vite app.
- `public` — static assets.
- `dist` — generated production build output.

Run the application from this directory with `npm run dev` and create a production build with `npm run build`.
